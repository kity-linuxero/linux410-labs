## 🐧 Bienvenidos

Esta es la guía de laboratorios prácticos del curso de **Administración de Servidores GNU/Linux con orientación en seguridad informática**.

Acá vamos a ir armando, paso a paso, el entorno de trabajo y las prácticas que acompañan a las clases teóricas: desde levantar nuestra primera máquina virtual hasta administrar y asegurar un servidor Linux.

Cada laboratorio es autocontenido: tiene sus objetivos, los pasos con capturas de pantalla, un resumen de lo visto y links útiles para profundizar.

> Esta guía está en construcción: se van publicando los laboratorios a medida que avanzamos con el curso.
