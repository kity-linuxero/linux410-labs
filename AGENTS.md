# Laboratorios del curso

Este repositorio contiene las guías prácticas y su README. Forma parte del espacio `curso-linux`; el programa, apuntes y seguimiento están en el repositorio hermano exterior. Cuando ese espacio esté disponible, leer `../AGENTS.md` y `../seguimiento/estado-actual.md` antes de preparar una práctica.

Leer el laboratorio anterior completo para respetar la continuidad de VM, cuentas y archivos. Conservar el formato de las guías, probar los pasos en la VM real cuando corresponda y registrar el resultado en `../clases/claseNN/validacion-laboratorio.md`. Revisar el README y los enlaces desde la presentación. Comprobar el estado Git y distinguir prueba local de publicación.
